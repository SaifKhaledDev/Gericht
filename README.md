# Gericht

A modern fine dining restaurant website built with React and Vite.

## Live Demo

https://gericht-sooty.vercel.app/

## GitHub

https://github.com/SaifKhaledDev/Gericht

## About The Project

Gericht is a responsive restaurant website inspired by modern fine dining experiences.

The project focuses on clean UI, responsive layouts, reusable React components, and a smooth user experience across different screen sizes.

## Built With

- React.js
- Vite
- JavaScript
- Tailwind CSS
- HTML5
- CSS3

## Features

- Responsive design
- Modern restaurant landing page
- Hero section
- About section
- Chef section
- Menu sections
- Awards and recognition section
- Instagram gallery
- Contact section
- Newsletter section

## Installation

Clone the repository:

```bash
git clone https://github.com/SaifKhaledDev/Gericht.git
```

Go to the project folder:

```bash
cd Gericht
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

```bash
npm run build
```
